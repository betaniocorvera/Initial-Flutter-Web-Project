TutorMatch A.I.

A Tutor-Student Matching and Recommender System using K-Nearest Neighbors.

Made for IT 110 - Web Systems and Technologies (Laboratory Activity 8).

About

TutorMatch A.I. helps students find tutors that fit them. This repository is the starting Flutter Web project with a basic Login, Registration, and Dashboard screen. It uses sample data only, with no backend or database yet.

How to run

You need Git, the Flutter SDK, and Google Chrome.

git clone https://github.com/betaniocorvera/Initial-Flutter-Web-Project.git
cd Initial-Flutter-Web-Project
flutter pub get
flutter run -d chrome
